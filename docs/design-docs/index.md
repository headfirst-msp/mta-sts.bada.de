# Design docs

Short records of decisions that shape the project. One decision per file, numbered
in order: `0001-<topic>.md`.

Each record states the context, the decision, the alternatives that were rejected
and why, and the consequences. Do not edit an accepted record. Write a new one that
supersedes it and link the two.
